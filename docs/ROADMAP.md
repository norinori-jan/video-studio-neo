# Development roadmap

1. Project foundation — current scaffold
2. Native desktop integration — Tauri 2, Rust, atomic project save, media directory policy
3. Media ingestion — ffprobe metadata, thumbnails, missing-media and relink workflow
4. Shared timeline core — frame/timebase math, clip operations, undo/redo
5. Preview proof of concept — native macOS decoding/playback evaluation
6. Simple editing — arrange, trim, split, titles, BGM and fades
7. Professional foundation — multi-track controls, keyframes, detailed properties
8. Export — local FFmpeg process supervision, progress, cancel, output validation
9. Packaging — local assets, signing/notarization plan, FFmpeg license review
10. macOS acceptance — real device smoke tests and media fixtures
