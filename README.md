# Video Studio Neo 0.5.0

開発用ブラウザプロトタイプ。React + TypeScript + Vite。

## PowerShell
```powershell
npm install
npm test
npm run build
npm run dev
```
`http://127.0.0.1:5173/` を開きます。

## 実装した範囲
- 動画・音声・画像の複数読み込み、ファイル情報取得
- メディアビン、ダブルクリック/ボタンでタイムラインへ配置、ドラッグ&ドロップ配置
- マルチトラック、トラック追加、ミュート状態
- クリップ選択、名前/開始位置/尺/素材開始位置/音量の編集
- クリップ分割・削除、Undo/Redo
- 再生ヘッド、簡易プレビュー、字幕テキスト編集、解像度/FPS設定
- JSONプロジェクト保存/読込
- 読み込み時のプロジェクト構造・クリップ値のランタイム検証（0.5.0）
- 現在の動画要素をWebMキャプチャする実験的な書き出し

## 重要な未実装/制限
これは「全機能完成版」ではなく、予定機能をまとめた開発プロトタイプです。Tauri 2/Rust統合、ネイティブFFmpeg、フレーム精度の合成再生、複数映像トラックの合成、音声ミックス、トランジション、キーフレーム、カラー調整、波形/サムネイル、プロキシ、メディア再リンク、SQLite、自動保存、Mac署名/公証は未実装です。
素材URLはブラウザの一時URLで、JSONには素材本体が入りません。再読込後は素材の再指定が必要です。WebMキャプチャは現在の単一video要素のみで、タイムライン全体の正確な書き出しではありません。Google Fonts CDNを使うため完全オフラインではありません。

## 0.5.0の変更
